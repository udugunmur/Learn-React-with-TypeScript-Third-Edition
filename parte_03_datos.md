# Parte 3: Datos

Esta parte cubre diferentes enfoques para interactuar con los datos de una base de datos en un servidor, con sus beneficios y ventajas y desventajas (*trade-offs*). Incluye la obtención de datos mediante **React Server Components** y **React Client Components**. También incluye la mutación de datos utilizando **React Server Functions** y varios enfoques de formularios para capturar los datos de la mutación.

Esta parte contiene los siguientes capítulos:

- [Capítulo 7](https://subscription.packtpub.com/book/web-development/9781836643173/7): Obtención de datos con Server Components y mutaciones con Server Functions
- [Capítulo 8](https://subscription.packtpub.com/book/web-development/9781836643173/8): Obtención de datos en Client Components y mutaciones con TanStack Query
- [Capítulo 9](https://subscription.packtpub.com/book/web-development/9781836643173/9): Trabajo con formularios
