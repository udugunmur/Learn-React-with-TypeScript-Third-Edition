# Parte 2: Fundamentos de la Aplicación

Esta parte cubre temas fundamentales clave para la creación de aplicaciones, comenzando con diferentes **enfoques de estilos** y sus beneficios. Luego se explora el uso de los **React Server Components** y los casos de uso donde destacan. La parte concluye con la construcción de una **aplicación de múltiples páginas** utilizando el popular framework de React, **Next.js**.

Esta parte contiene los siguientes capítulos:

- [Capítulo 4](https://subscription.packtpub.com/book/web-development/9781836643173/4): Enfoques para estilizar frontends en React
- [Capítulo 5](https://subscription.packtpub.com/book/web-development/9781836643173/5): Uso de React Server y Client Components
- [Capítulo 6](https://subscription.packtpub.com/book/web-development/9781836643173/6): Creación de una aplicación multipágina con Next.js
