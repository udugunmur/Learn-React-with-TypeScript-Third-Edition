# Parte 4: React Avanzado

Esta parte cubre temas avanzados de React. Comienza con diferentes enfoques para compartir el estado entre componentes en una aplicación con sus respectivos beneficios. Luego se exploran diferentes patrones para implementar componentes altamente reutilizables y seguros en cuanto a tipos (*type-safe*). La parte finaliza con cómo implementar pruebas automatizadas en los componentes, lo que nos da la confianza para lanzar nuevas características en las aplicaciones rápidamente.

Esta parte contiene los siguientes capítulos:

- [Capítulo 10](https://subscription.packtpub.com/book/web-development/9781836643173/10): Gestión del estado (*State Management*)
- [Capítulo 11](https://subscription.packtpub.com/book/web-development/9781836643173/11): Componentes reutilizables
- [Capítulo 12](https://subscription.packtpub.com/book/web-development/9781836643173/12): Pruebas unitarias con Vitest y React Testing Library
