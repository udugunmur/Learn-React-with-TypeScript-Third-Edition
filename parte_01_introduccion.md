# Parte 1: Introducción

Esta parte te permitirá dar los **primeros pasos tanto con React como con TypeScript**, aprendiendo cómo crear un nuevo proyecto e implementar componentes interactivos y con tipado seguro (*type-safe*). También aprenderemos en detalle sobre los **Hooks comunes de React** y los casos en los que se utilizan en las aplicaciones.

Esta parte contiene los siguientes capítulos:

- [Capítulo 1](https://subscription.packtpub.com/book/web-development/9781836643173/1): Primeros pasos con React
- [Capítulo 2](https://subscription.packtpub.com/book/web-development/9781836643173/2): Primeros pasos con TypeScript
- [Capítulo 3](https://subscription.packtpub.com/book/web-development/9781836643173/3): Uso de React Hooks
